 MultiClass Lung Disease Detection Using XAI

📌 Project Overview
This project uses Machine Learning / Deep Learning techniques to detect lung diseases and provides Explainable AI (XAI) insights.

⚙️ Features
- Lung disease classification
- Explainable AI (XAI) visualization
- Confusion matrix analysis
- Simple deployment-ready scripts

🧠 Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- Matplotlib
- Scikit-learn

📊 Outputs
- Confusion Matrix
- Model Predictions
- Visualization plots

▶️ How to Run
```bash
pip install -r requirements.txt
python app.py
